
## Planck bandpass
We copied Planck passbands for LFI and HFI in the `planck_bandpass` directory. The original files are from the public `pyilc` software (https://github.com/jcolinhill/pyilc/tree/main)

## SIDES SED library
We copied the IDL saveset containing the SED library used in the SIDES model from https://gitlab.lam.fr/mbethermin/sides-public-release/-/tree/main/PYSIDES/pysides/SEDfiles?ref_type=heads. It contains SED as a function of the mean intensity of the radiation field for MS and SB galaxy populations.
